# Regret OS v2.4.1 — 决策引擎

> 把你的**黑历史**变成决策燃料的黑客终端。
> TRAE 项目比赛作品 · 命题组合：黑历史 × 决策器 × 黑客终端风

## 这是什么

一个运行在浏览器里的**离线决策终端**。你把犹豫不决的问题敲进去（"我该不该裸辞创业？"），
Regret OS 会扫描内置的 1,247 条黑历史档案，跑完六步多维分析，然后给出一份带依据的判决书——
风险因子、替代方案、档案引用，一应俱全。

全程无后端、无网络请求、零依赖。它嘴很严：因为它根本没有嘴，也不联网。

## 命题映射

| 命题 | 在作品中的体现 |
|------|----------------|
| 主题词 · 黑历史 | regret-archive 数据源：12 条可读档案 + 隐藏库 1,247 条；`remember` 命令可继续录入；判决书会引用具体档案编号 |
| 功能词 · 决策器 | 决策引擎核心：自然语言提问 → 关键词识别五大领域（事业/感情/财务/社交/人生）→ 确定性伪随机判决（同一问题永远同一答案）|
| 风格词 · 黑客终端风 | 全终端 UI：绿字荧光、开机自检日志、逐字打字机、扫描线 CRT、故障闪烁、状态栏遥测 |

## 功能清单

- **开机仪式**：逐行 boot 日志 + ASCII 打字机 + 自动演示（页面加载后自动完成一次完整判决流程）
- **决策引擎**：底部命令栏提问，六步分析动画 + 进度条 + 四种判决（推荐 / 谨慎推进 / 暂不推荐 / 证据不足）
- **中英双语提示**：侧边栏、开机日志、分析步骤、面板标题、判决副标题均带中文对照，纯终端风格不牺牲可读性
- **面板直达**：URL hash 深链，`index.html#history` / `#profiles` / `#about` 等可秒开任意面板，方便演示
- **黑历史档案**（HISTORY）：12 条预置档案 + 本次会话的提问记录；`remember <黑历史>` 命令随时录入
- **完整面板**：PROFILES / DATASOURCES / SETTINGS / LOGS / DIAGNOSTICS / ABOUT 均为有数据的实页面，无死链
- **终端彩蛋**：`sudo` / `exit` / `help` / `stats` / `clear` 命令；`/` 快捷键聚焦输入框
- **实时遥测**：时钟、uptime、CPU/RAM/GPU 假负载、波形动画

## 运行方式

零构建、零依赖，三选一：

```bash
# 1. 直接双击 index.html

# 2. 本地静态服务（推荐）
npx serve .
# 或
python -m http.server 8000

# 3. 任意静态托管：把整个文件夹丢上 GitHub Pages / Netlify / Vercel
```

## 技术说明

- **纯前端**：无任何网络请求，`file://` 直开可用；"MODE: offline" 不是装饰，是事实
- **确定性判决**：djb2 哈希 + mulberry32 伪随机种子，同一问题永远得到同一判决——引擎记得你问过
- **IME 兼容**：中文输入法组词期间不会误触发提交
- **无障碍细节**：`prefers-reduced-motion` 降级、键盘可达、语义化按钮
